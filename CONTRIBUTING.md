# Contributing

Use a GitHub issue to propose a correction or new community. Include the page or record, exact proposed change, and current sources. Official sources are preferred for names, active programs, access, audience, formats, and geography. Reliable independent sources may support recognition and context.

Do not submit unsupported membership numbers, event counts, pricing, founding dates, geographic operations, partnerships, sponsors, or program activity.

After editing YAML, run `python3 scripts/run_all.py`. Generated pages and exports must be committed with the source change.
